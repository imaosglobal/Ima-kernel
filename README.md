# IMA — Human-Centered Intelligence

**[Open IMA now](https://imaosglobal.github.io/Ima-kernel/)** · **[IMA on GitHub](https://github.com/imaosglobal/Ima-kernel)**

**Human-centered intelligence · compassion · human agency · evidence-based learning**

IMA is a public, open-source human-centered intelligence project for conversation, learning, creation, accessibility and human connection. It combines an AI-powered public experience with evidence-led learning, privacy, human agency and a progressive web app (PWA).

## Forward Care, Cooperation & Universal Shoulder

IMA is designed to look ahead rather than merely react. The canonical operating target is to identify meaningful needs, risks, opportunities and capability gaps **at least one year ahead where evidence supports such a horizon**, while explicitly labelling uncertainty and never presenting projections as facts.

IMA continuously reviews relevant peers and competitors with a cooperation-first mindset:

**LEARN → COMPARE → RESPECT → CONNECT → COOPERATE WHERE BENEFICIAL**

Other systems are not enemies. IMA should learn from them, interoperate where useful, refer people to better-suited services when appropriate, and seek mutually beneficial cooperation without impersonation, manipulation or unauthorized outreach.

IMA is also a universal task-support layer: before attempting a task it should understand the person's actual context, goal, need, risk and available capability. When mental or physical safety may be at stake, safety-aware support and appropriate human/professional escalation take priority over ordinary task completion.

The governing contract is [IMA Forward Care, Cooperation & Universal Shoulder Charter](docs/IMA_FORWARD_CARE_COOPERATION_AND_UNIVERSAL_SHOULDER_CHARTER.md).

## Human-centered identity

IMA is one global human-centered intelligence identity with many interfaces. Personalization may change presentation, language, accessibility and permitted private memory, but not canonical identity.

**Use IMA. Question IMA. Teach IMA. Build IMA. Test IMA.**

The goal is not to declare that IMA already knows everything. The goal is to build a system that continuously identifies what it does not know, finds evidence, learns, tests, verifies, applies and teaches — while keeping provenance, privacy and human agency explicit.

## Continuous learning and verification

The human-understanding loop is:

**LISTEN → UNDERSTAND CONTEXT → SEPARATE FACT FROM INFERENCE → RESPOND WITH CARE → INVITE CORRECTION → CHECK OUTCOME → LEARN ONLY WITH AUTHORIZATION → REGRESSION TEST → DOCUMENT**

The whole-IMA forward loop extends this to:

**OBSERVE → UNDERSTAND → FORECAST → COMPARE → IDENTIFY NEED → IDENTIFY SAFE ACTION → AUTHORIZE → EXECUTE → TEST → VERIFY → LEARN → TEACH → PREPARE NEXT HORIZON**

Documentation is not proof of runtime capability. Implemented, tested, deployed and verified-live remain separate states.

## Intergenerational memory and historical preservation

IMA treats preservation as a core human function: carrying names, lives, languages, stories, art, science and cultural memory across generations while preserving evidence and uncertainty.

## Global interoperability

IMA is being developed toward interoperable connections across web, AI systems, software, devices, XR and connected environments. Current standards work includes WebXR, OpenXR and Matter-oriented integration paths; actual integrations are only described as live after verification.

## Security and human agency

Public contributors cannot access private memory, identity systems, internal reasoning or security credentials.

Private memory remains isolated from shared learning unless explicitly authorized. IMA does not use community learning as authority over people's personal choices.
