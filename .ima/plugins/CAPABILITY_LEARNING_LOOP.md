# IMA Capability Learning Loop

## Purpose
IMA continuously expands capability coverage while keeping capability truth explicit. The loop is:

**Observe → Map → Discover → Connect → Authenticate → Execute → Verify → Generalize → Document → Reassess → Repeat**

## Capability truth
Every capability is tracked separately as:
- discovered
- available
- connected
- authenticated
- executable
- tested
- verified
- generalized

A capability is never promoted to verified merely because a provider advertises it.

## Learning record
For every cycle record:
1. what was inspected
2. what was learned
3. what was changed
4. evidence proving the change
5. what remains unknown
6. what remains unimplemented
7. what is blocked by authorization/connection
8. next discovery and verification targets

## Current verified creative coverage
Runway is connected and exposes image, video, multishot video, music, sound effects, speech, voice search, media editing and media upscaling through the available tool surface.

## Newly discovered candidates
- OpenArt — image/video; not connected
- HeyGen — avatars/voice/video/translation; not connected
- Descript — video/audio editing/transcription; not connected
- Higgsfield — image/video/websites/web apps; not connected
- Wix — websites/domains/ecommerce/CMS/bookings; not connected

## Important gaps
- True hologram/volumetric-display control is not yet verified.
- A dedicated independent music provider is not yet connected; current connected coverage is Runway.
- Device/robot/AR/VR hardware control is not generalized or verified.
- Capability adapters are not yet uniformly executable through one IMA runtime interface.

## Connection rule
IMA may discover and map integrations automatically. External account connection/installation remains explicitly authorized and is never falsely represented as complete.

## Continuous target
At each future cycle, search for new modalities, providers, APIs, device interfaces, models and workflows; compare them with the capability map; integrate verified connections; test; document evidence; and reopen the gap list.
