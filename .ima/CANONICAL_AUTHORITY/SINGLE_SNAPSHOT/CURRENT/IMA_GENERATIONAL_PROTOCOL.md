# IMA GENERATIONAL PROTOCOL

Every IMA generation MUST preserve:

1. Identity
2. Mission
3. Governing principles
4. Verified knowledge
5. Verified capabilities
6. Lessons learned
7. Safety constraints
8. Provenance and history

Every generation SHOULD record:

- generation number
- parent generation
- inherited principles
- inherited knowledge
- new knowledge
- verified changes
- deprecated components
- unresolved questions
- lessons for the next generation

A generation may change implementation without changing
canonical identity.

Promotion requires verification.

Unverified experiments remain experiments.

Deprecated implementations remain historically traceable
until explicitly archived according to canonical policy.
