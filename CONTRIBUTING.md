# Contributing to IMA

IMA is an open project by Ori Cohen for building a human-centered intelligence layer that can preserve knowledge, connect capabilities, learn, create and act while preserving human agency.

## You do not need permission to help IMA

Find something you can improve, build it, test it, document it, and open a Pull Request.

## Contribution flow

1. Read the repository README and canonical vision.
2. Search existing Issues and Discussions before starting duplicate work.
3. Choose an existing issue or open a proposal.
4. Fork the repository or create a branch.
5. Make a focused change.
6. Run the relevant tests and checks.
7. Preserve provenance for knowledge and derived artifacts.
8. Open a Pull Request describing what changed and how it was verified.

## Principles

- Human agency remains with humans.
- Original works must never be overwritten by translations or derivatives.
- Derivatives must retain provenance and their parent artifact.
- Prefer additive, reversible changes.
- Do not commit secrets, credentials or private data.
- Do not silently disable safety, verification or provenance controls.
- Do not make destructive automated changes to the repository.
- Preserve the canonical IMA vision.

## Good contributions

- Bug fixes
- Tests
- Documentation
- Accessibility
- Hebrew and multilingual support
- 3D/UI improvements
- Memory and provenance systems
- Agent/tool integrations
- Security improvements
- Preservation and portability
- Research implementations
- Developer tooling
- Reproducible experiments

## First-time contributors

Look for issues labelled `good first issue`, `help wanted`, `documentation`, or `community`.

You can also open a Discussion to propose an idea before implementing it.

## Pull Requests

Every PR should explain:

- What changed
- Why it matters
- How it was tested
- What files or systems are affected
- Whether it changes preservation, provenance, identity, safety or governance

IMA uses automated checks before changes are accepted into the main development line.
