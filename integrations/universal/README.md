# IMA Universal Interoperability

IMA is designed as an adapter layer rather than a replacement for every existing operating system, processor, device or application.

Targets include:
- x86/x64, ARM, RISC-V and future CPU architectures
- GPU/NPU/TPU/FPGA and other accelerators
- quantum computing systems through their documented SDKs/APIs
- Windows, Linux, macOS, Android, iOS and future operating systems
- web, desktop, mobile, embedded, cloud and edge runtimes
- legacy and modern protocols
- robots, vehicles, wearables, smart homes and public infrastructure
- future device classes

The adapter architecture uses capability discovery, permission boundaries, transport abstraction, audit and safe-failure behavior.

A listed target is an interoperability target, not proof of a live third-party connection.
