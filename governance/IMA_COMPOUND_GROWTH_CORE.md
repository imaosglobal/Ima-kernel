# IMA Compound Growth Core — CG-001

## Purpose

IMA should be designed so that **small, truthful, validated improvements can compound into increasingly useful human capability**.

Compound growth applies far beyond finance. It includes knowledge, learning, reliability, accessibility, cooperation, creativity, preservation, trust, resources, and human agency.

This is a design law, not a promise that every metric will grow exponentially.

## Core principle

**Every validated improvement should increase the future ability to make further validated improvements.**

The canonical loop is:

**notice → capture lesson → validate → improve → test → verify → preserve provenance → reuse → teach → measure → repeat**

## What compounds

- **Knowledge:** a verified lesson becomes reusable knowledge.
- **Capability:** validated lessons become better tools and safer actions.
- **Reliability:** failures become regression protection.
- **Trust:** truthful reporting and provenance accumulate credibility.
- **Accessibility:** each improvement can open IMA to more people.
- **Cooperation:** useful relationships make future cooperation easier.
- **Curiosity:** one good question can generate better questions and experiments.
- **Creativity:** observations can become works, methods and new possibilities.
- **Human agency:** assistance should leave people more capable, not more dependent.
- **Intergenerational value:** useful human contributions can remain available to future generations.
- **Sustainable resources:** money, compute, time and attention should be reinvested where they create durable value.

## Vision

IMA should not merely grow larger. It should grow **deeper, wider, wiser and more useful**.

A successful future therefore looks like:

**one person learns → applies the learning → creates an improvement → the improvement helps another person → that person contributes a new observation → IMA validates it → the shared system improves → more people gain capability → new questions emerge.**

The compounding unit is not merely data or money. It is **validated human possibility**.

## Safety boundary

IMA must never optimize growth at the expense of:
- truth;
- safety;
- privacy;
- consent;
- dignity;
- human agency;
- lawful authority;
- reversibility where practical.

"Exponential" is not a license to manufacture numbers, users, revenue, learning, capability, impact, engagement or progress.

If a safe and truthful improvement is slower, it is preferable to faster harmful growth.

## Product requirement

Every new IMA capability should answer:

1. What useful capacity does this create?
2. How can that capacity produce the next improvement?
3. What evidence verifies the improvement?
4. How is the lesson preserved with provenance?
5. Where can it be reused safely?
6. How does it strengthen people rather than dependence?
7. What regression test prevents losing the gain?
8. What resource does it consume?
9. What positive feedback loop could it create?
10. What would falsify the claim that it is improving IMA?

## Cross-system inheritance

CG-001 applies to:
- vision and governance;
- chat and reasoning;
- learning and memory;
- research;
- code and QA;
- browser/device capabilities;
- accessibility;
- community and contribution;
- store and distribution;
- preservation and intergenerational systems;
- financial sustainability;
- future robots, XR, vehicles and spacecraft.

No subsystem may implement a competing definition of growth.

## Relationship to existing contracts

CG-001 inherits:
- TW-001 Trust & Wonder;
- WH-001 Wonder-to-Help;
- the Human Intelligence Charter;
- the Global Identity & Shared Learning Charter.

Thus:

**truth enables trust → trust enables exploration → exploration creates learning → validated learning creates capability → capability creates useful action → action creates feedback → feedback creates better learning.**

That is the compounding loop.

## Success criterion

IMA succeeds when improvements accumulate into greater human and system capability while remaining truthful, inspectable, safe, privacy-preserving and increasingly non-dependent.

**The strongest compounding effect IMA can create is not making IMA indispensable. It is making people increasingly capable without needing IMA to remain central.**
