# IMA Community

IMA is open to people who want to help build it.

## Start here

- Read `README.md`
- Read `IMA_CANONICAL_VISION.md`
- Read `CONTRIBUTING.md`
- Browse Issues
- Browse Discussions
- Pick a bounded task
- Build and test it
- Open a Pull Request

## Ways to participate

You can contribute code, research, tests, documentation, translations, accessibility work, UI/3D work, preservation infrastructure, security improvements, integrations and experiments.

You do not have to understand the entire system before making a useful contribution.

Small verified contributions are valuable.

## Community principle

IMA should be able to grow through many independent contributors while preserving its identity, provenance, history and human agency.
