# IMA Support

For project participation:

- Use GitHub Issues for bugs, features and concrete tasks.
- Use Discussions for questions, ideas and broader project conversations.
- Use Pull Requests for implementation.
- Use the security reporting process in `SECURITY.md` for security-sensitive matters.

Before opening a new issue, search existing issues and the Community Roadmap.

Useful entry points:

- `DISCOVER_IMA.md`
- `CONTRIBUTING.md`
- `COMMUNITY_ROADMAP.md`
- `GOVERNANCE.md`
- `SECURITY.md`
