# IMA Community Code of Conduct

IMA is intended to be developed as a global, human-centered project.

Participants are expected to:

- Treat other contributors with respect.
- Discuss ideas and code rather than attacking people.
- Welcome different cultures, languages and technical backgrounds.
- Give credit to previous work.
- Preserve provenance.
- Respect human agency.
- Report security or privacy problems responsibly.
- Avoid harassment, discrimination, threats and deliberate disruption.

Project maintainers may moderate contributions that violate these principles.

The goal is a productive environment where people can build, test, question and improve IMA together.
