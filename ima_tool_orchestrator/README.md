# IMA Tool Orchestrator

Goal → Plan → Capability Discovery → Policy Gate → Adapter → Verification → Provenance → Learning.

External services are adapters, not hard dependencies. Registry presence never means a live connection exists.

Registry: ChatGPT/OpenAI, Claude/Anthropic, Hugging Face, Zapier, HubSpot, Canva, Midjourney, and generic finance APIs.

Initial adapters are discovery-only until authenticated connectors are configured. This prevents false claims of execution.

High-risk actions require explicit authorization; secrets are never stored here.
