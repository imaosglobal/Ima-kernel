# IMA Global Community Roadmap

This roadmap is for independent contributors.

The goal is to let people improve IMA without requiring direct coordination with the founder.

## Start anywhere

### 1. Make IMA easier to use
- Improve onboarding
- Improve accessibility
- Improve mobile experience
- Improve Hebrew and RTL support
- Improve multilingual support

### 2. Make IMA more capable
- Memory
- Voice
- 3D embodiment
- Tool use
- Agent capabilities
- External AI integrations
- Autonomous workflows

### 3. Make IMA more trustworthy
- Tests
- Security
- Provenance
- Verification
- Human-agency protections
- Reproducibility

### 4. Preserve IMA across generations
- Artifact preservation
- Content addressing
- Portable identity
- Translation provenance
- Format migration
- Independent verification
- Recovery procedures

### 5. Research
- Human-centered intelligence
- Embodied intelligence
- Compassionate interaction
- Long-term memory
- Knowledge preservation
- Multi-agent systems
- Future interfaces

## How to contribute

Choose one small, concrete problem.

Build it.

Test it.

Document it.

Open a Pull Request.

You do not need to understand the entire IMA system before contributing.

## Community rule

No contributor owns the future of IMA alone.

Contributions should remain inspectable, attributable, testable and reversible wherever technically possible.
