# IMA Browser Bridge Privacy Policy

Effective: 2026-11-01

IMA Browser Bridge is designed to minimize browser data access.

## Data we access

When the user explicitly chooses “Read current page”, the extension reads the current page URL, title, visible text, and timestamp. Visible text is limited to 20,000 characters.

## Data we do not access

The extension does not request the Chrome cookies permission and does not export cookies, passwords, saved payment credentials, or browser history.

## Optional transmission

The extension does not send page content to a server unless the user explicitly configures an HTTPS IMA endpoint in Settings. If configured, the extension sends the page URL, title, visible text, timestamp, extension version, and event type to that endpoint.

## User control

The user can disable the bridge or remove the configured endpoint at any time. Financial, destructive, permission-changing, publishing, and irreversible actions are not automated by this release.
