# Discover IMA

IMA is an open, human-centered intelligence project by Ori Cohen.

The project is open to independent contributors worldwide.

## What can you build?

- AI agents and tool use
- Memory and provenance
- 3D embodiment
- Voice and multimodal interaction
- Accessibility
- Hebrew, RTL and multilingual support
- Knowledge and artifact preservation
- Security and verification
- Research and experiments
- Developer tooling

## Start contributing

1. Read the canonical vision.
2. Read CONTRIBUTING.md.
3. Browse Issues and Discussions.
4. Choose a small task labelled `help wanted` or `good first issue`.
5. Build and test your contribution.
6. Open a Pull Request.

You do not need permission from the founder to start working on an existing community task.

## Project principles

IMA is intended to grow through many independent contributors while preserving:

- human agency
- provenance
- attribution
- original artifacts
- verifiability
- portability
- historical continuity
