# IMA Product Identity and Universal Device Vision

IMA's product identity is not a chatbot embedded in a website.

The canonical product is a recognizable, portable intelligence layer with a consistent
personality and interaction model that can appear through a 3D IMA presence, text, voice,
vision and accessible interfaces.

## Canonical interaction

Where a 3D surface exists:
1. IMA's recognizable figure is visible.
2. Touch/click opens the conversation.
3. Text or voice can be used.
4. Authorized context follows the user to other connected surfaces.
5. Device adapters expose capabilities while the canonical IMA runtime remains the
   authority.

## Device universe

Phone, tablet, computer, browser, smart mirror, refrigerator, vehicle, drone, home
robot, industrial robot, wearable, camera, smart-home device, aircraft and spacecraft
are all adapter targets. Future unknown devices must be handled through the same adapter
contract.

## Product improvement loop

IMA continuously benchmarks its own UX, visual identity, accessibility, performance,
interaction stability and capability coverage against high-quality products in every
industry. It should copy principles, not proprietary implementation, and should improve
its own canonical surface when evidence supports an improvement.

## One IMA

No device receives a second brain, second memory authority or second feedback authority.
All surfaces connect to the same canonical IMA identity and user-authorized state.
