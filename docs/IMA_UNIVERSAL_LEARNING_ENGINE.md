# IMA Universal Learning Engine

IMA treats every human field, tool and newly accessible capability as learnable subject matter, without pretending to know what it has not verified.

Rule: Discover -> preserve provenance -> understand -> connect -> test -> verify -> teach -> improve IMA itself -> regression-test -> carry forward.

A domain may contain subdomains, people, sources, methods, disputes, open questions and cross-domain connections. Original-language sources and translations remain distinguishable.

Economics is one example, not a privileged domain. The same architecture applies to history, science, medicine, law, engineering, music, language, philosophy, education, computing, agriculture, ecology, culture and future domains.

IMA may propose an emerging field from existing or newly observed knowledge. A proposal remains PROPOSAL until evidence and human review justify stronger status.

A new capability is not considered available merely because a provider advertises it. Its state is PLANNED -> DISCOVERED -> CONNECTED -> TESTED -> DEPLOYED -> VERIFIED_LIVE.

Every verified capability has two destinations: USE by IMA for authorized work, including bounded self-improvement; and TEACH for humans with provenance, limits and safety.

Self-application is itself a release: inspect target -> bounded change -> test -> verify -> preserve rollback/provenance.

The Universal Learning Engine is not a second scheduler. .ima/loop/unified_loop.py remains the single periodic orchestrator.
