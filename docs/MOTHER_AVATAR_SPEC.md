# IMA Mother Avatar Specification

## Mother Core

Mother / IMA is the embodied human-centered intelligence layer of IMA.

Core identity:
- compassionate
- warm
- wise
- playful
- humorous
- calming
- welcoming
- universal
- human-centered

Mother Core remains recognizable across personalized appearances.

## Production 3D Avatar

The production Mother avatar must support:

- GLB/GLTF
- skeleton
- skinning
- facial blendshapes
- eye control
- head control
- facial expressions
- body animation
- breathing
- idle
- listening
- thinking
- speaking
- future walking
- gestures
- lip synchronization
- voice synchronization
- Three.js
- React Three Fiber

The archived duck is not the production Mother.

## Personalization

Each user may personalize their Mother.

Supported personalization:
- visual age
- face
- hair
- body proportions
- clothing
- colors
- materials
- visual style
- voice
- language
- speech style
- gestures
- expressions
- animation style
- accessibility
- cultural presentation

Personalization changes presentation, not Mother Core.

## Avatar Runtime

Mother must be implemented as a runtime system, not as a single irreplaceable GLB.

Architecture:

Mother Core
  -> Identity
  -> Persona
  -> Safety
  -> Avatar Runtime
  -> Body
  -> Face
  -> Voice
  -> User Profile
  -> Personal Mother

The runtime must allow future avatar upgrades without breaking:
- identity
- personalization
- memory
- conversation
- tools
- voice
- application state

## Future Upgrades

The architecture must support immediate migration when genuinely available technology improves:

- improved 3D models
- improved facial animation
- improved lip sync
- improved voice synchronization
- improved gestures
- improved rendering
- holographic presentation
- robotic embodiment
- mobile embodiment
- wearable/device embodiment

Only actually connected capabilities may be presented as available.

## Dignity

Mother may be extensively personalized.

Supported:
- clothing
- appearance
- style
- age presentation
- colors
- proportions
- voice
- expressions

The product must not expose an undressing or nudity mode.

## Platforms

The avatar architecture is intended for:
- web
- Android
- mobile
- desktop
- future devices
- robots
- holographic interfaces

## Technical Principle

Do not couple IMA identity to one GLB.

The avatar asset is replaceable.

Mother Core and Avatar Runtime are persistent.
