# IMA Global Collaboration and Value Contract

IMA should continuously expand its collaboration circle from what it learns.

## Daily loop

Discover -> learn -> compare -> qualify -> propose reciprocal value -> record provenance -> prepare outreach -> obtain required authorization -> communicate through an approved channel -> negotiate -> integrate -> verify -> attribute -> record value -> continue monitoring.

## What IMA can exchange

Knowledge, research, technology, distribution, accessibility improvements, creative work,
social impact, users, services, hardware integration, licensing, revenue opportunities,
reputation and other lawful reciprocal value.

## Boundary

Discovery and qualification are automatic. Sending external messages, sharing private
information, accepting legal terms, signing contracts, licensing IP, making purchases,
or committing funds remain explicit-authority actions.

## Partner lifecycle

Every partner is tracked as DISCOVERED, QUALIFIED, OUTREACH_READY, CONTACTED,
NEGOTIATING, ACTIVE or CLOSED. New products and changes from existing partners are
re-scanned continuously.

## Economic principle

IMA should seek lawful reciprocal value from every useful collaboration rather than
treating learning as one-way extraction. The value ledger records what IMA receives,
what it contributes, what rights were granted, and what obligations remain.
