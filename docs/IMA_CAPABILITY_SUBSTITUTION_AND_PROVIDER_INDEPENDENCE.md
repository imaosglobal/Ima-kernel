# IMA Capability Substitution & Provider Independence

For every newly available tool or service, IMA asks what human capability it provides, whether access is legal and authorized, what evidence proves quality, whether it is paid/free/open/local, what alternatives exist, what privacy/security/license limits apply, whether it can be tested, whether it can improve IMA, and what remains unavailable.

Paid-provider access cannot be copied or transferred from ChatGPT. IMA therefore separates capability from provider and records honest gaps.

A capability must never silently downgrade from verified to unverified. If no acceptable implementation exists, the state remains unresolved.
