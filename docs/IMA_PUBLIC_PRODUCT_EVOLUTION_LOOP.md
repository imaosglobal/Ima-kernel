# IMA Public Product Evolution Loop

## Purpose
The public IMA experience is treated as a continuously improving product, not a finished page.

## Non-negotiable UX contract
1. One primary Google sign-in entry on the public landing experience.
2. Every visible control has one clear purpose and a tested destination/action.
3. No broken internal anchors, dead pages, accidental provider/studio links, or placeholder controls.
4. Language follows the user's explicit choice first, then browser/device language, with direction and layout adapted accordingly.
5. Accessibility targets WCAG 2.2 AA as the global baseline, while local legal requirements are checked separately where relevant.
6. Personalization is opt-in and user-controlled; the interface must not infer a disability or medical condition from behavior.
7. Support keyboard navigation, visible focus, screen readers, captions/transcripts, reduced motion, text resizing, high contrast, cognitive simplification, touch targets, and alternative input/output modes.
8. Preserve the user's agency: personalization never overrides safety, privacy, consent, law, or device constraints.
9. Keep public identity consistent across web, mobile, voice, avatar, community and shop.
10. Never claim a capability is working until it has reproducible evidence.

## Continuous loop
DISCOVER → MEASURE → REPRODUCE → FIX → TEST → DEPLOY → OBSERVE → LEARN → REGRESS → REVERIFY.

### Daily evidence
- build and deployment status
- public HTTP availability
- authentication configuration and flow health
- internal/external link integrity
- accessibility contract checks
- responsive layout checks
- PWA installability
- localization coverage
- button/action inventory
- YouTube/channel performance when connected
- user-visible failures and recovery paths

### Learning sources
Use official standards and documentation first, then high-quality public products and community patterns. Copy principles and validated interaction patterns, not proprietary code or protected content.

### YouTube growth loop
Measure impressions, click-through behavior, retention, satisfaction, traffic sources and subscriber movement. Improve titles, thumbnails, hooks, descriptions, translations and distribution based on evidence. Do not equate publication time with guaranteed reach.

### Safety
The loop may automatically apply low-risk, reversible UI fixes that pass tests. Changes affecting authentication, payments, privacy, permissions, external publishing or safety-critical behavior require explicit verification and appropriate authorization.
