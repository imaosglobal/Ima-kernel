# IMA 2026 Leading AI Capability Benchmark

Review date: 2026-10-03

OpenAI currently emphasizes agent APIs, tool orchestration, remote MCP, web/file search, computer use, background execution, tracing and subagents.

Google emphasizes a unified model/agent interface, multimodality, tool orchestration, conversation state, observable execution steps and background execution.

Anthropic emphasizes long-running agents, computer use, coding, context management and memory; its recent security reporting reinforces explicit permissions and sandboxing for consequential actions.

Apple emphasizes on-device foundation models, tool calling, context measurement and testing against changing OS model versions.

Highest-value IMA gaps:
1. Verified multi-provider orchestration.
2. Observable privacy-safe tool execution states.
3. User-facing background-task boundaries with authorization and cancellation.
4. Sandboxed computer use.
5. Model-version-aware capability tests and provenance.
6. On-device model adapters.
7. Verified bidirectional realtime voice.
8. Runtime-verified 3D Mother rendering with accessible fallback.
9. Complete multilingual localization.
10. Clear capability and permission evidence in UX.

Strategic conclusion: IMA should differentiate through one global identity, one personal relationship at a time, multi-model/tool interoperability, private-vs-shared memory separation, provenance, accessibility and human agency. Provider capabilities must never be presented as IMA capabilities until implemented and verified.

Primary sources reviewed: official OpenAI, Google, Anthropic and Apple developer/product documentation dated through 2026-10-03.
