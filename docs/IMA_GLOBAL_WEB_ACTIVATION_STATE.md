## Activation policy

A capability is marked LIVE only after runtime evidence exists. Documentation, a connector connection, or a design mockup alone is not proof of live deployment.

## Global website target

The public gateway should provide:
- one canonical IMA identity;
- multilingual RTL/LTR presentation;
- accessibility and voice;
- PWA/mobile continuity;
- conversation, learning, contribution and creation;
- provenance, privacy, consent and human-agency controls;
- evidence-driven global learning loop;
- measurable international acquisition, engagement and retention.
