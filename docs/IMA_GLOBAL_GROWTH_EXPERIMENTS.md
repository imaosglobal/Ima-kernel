# IMA — Global Growth Experiment System

All experiments must be small, measurable, lawful and reversible.

## Experiment families

### Discovery
SEO pages, answer-focused content, educational explainers, creator case studies, culture/history resources, accessibility resources.

### Activation
Fast first question, no unnecessary signup before value, clear Google sign-in, PWA install, multilingual onboarding, example prompts.

### Retention
Personal memory controls, continuity, saved creations, learning paths, daily usefulness, transparent changelog.

### Referral
Voluntary share cards, creator links, classroom links, cultural resources and public artifacts. No spam or forced invites.

### Community
Feedback, public issue reporting, educational partners, artists, researchers, teachers and cultural organizations.

### Trust
Visible privacy controls, data export/delete, provenance, capability truth and public status.

### Store
Verified listing, accurate metadata, real screenshots, real ratings and real reviews.

Every experiment records hypothesis, cohort, metric, result, decision and provenance.
