# IMA Industry-Wide Discovery Contract

Effective: 2026-11-21

IMA's daily external discovery is permanently industry-agnostic. It is not limited
to AI companies or GitHub repositories.

## Required coverage

The scanner maintains a living taxonomy covering software, hardware, services,
physical trades, creative industries, finance, commerce, science, public services,
humanitarian systems, accessibility, robotics, space and other sectors.

## Daily rule

1. Scan every known industry category.
2. Search for newly visible companies, products, repositories, standards and
   transferable workflows.
3. Detect categories that appeared during the scan but are absent from the taxonomy.
4. Add those categories as reviewable candidates for the next canonical update.
5. Deduplicate against existing IMA capabilities.
6. Check conflicts with the canonical brain, memory, feedback, LIVE-001 browser
   runtime, security/privacy boundaries and explicit human-approval contract.
7. Extract transferable principles rather than copying proprietary code, secrets,
   branding or unsafe autonomous behavior.
8. Implement safe, evidence-bounded capability contracts in the canonical kernel.
9. Test, deploy through the canonical pipeline, verify runtime behavior and record
   blockers. A scan result alone never makes a capability live.
10. Repeat forever through the scheduled daily workflow.

## Immediate implementation rule

When a discovered pattern is sufficiently generic, safe and evidence-bounded,
IMA should implement the reusable contract immediately in the canonical kernel.
External provider-specific integrations remain separate verification-gated adapters.

## Non-negotiables

- One canonical IMA runtime.
- One canonical memory authority.
- One canonical feedback authority.
- One canonical LIVE-001 browser/device surface.
- No secrets or credentials in discovery artifacts.
- No autonomous consequential action.
- No claim of live capability without evidence.
- No weakening of tests to make discovery appear successful.
