# IMA Learning Frontier

This is a machine-readable starting map of what IMA must continue to investigate.

The project does not claim that this list is complete. New questions, failures, technologies, evidence and teaching needs are expected to add new gaps.

## Gap classes

- `unknown`
- `uncertain`
- `conflicting_evidence`
- `missing_prerequisite`
- `missing_tool`
- `missing_interface`
- `missing_test`
- `missing_provenance`
- `failure_mode`
- `cross_domain_connection`
- `technology_upgrade`
- `teaching_opportunity`

## Learning cycle

KNOW -> MAP -> FIND GAPS -> DISCOVER -> LEARN -> CONNECT -> INFER -> TEST -> VERIFY -> APPLY -> TEACH -> OBSERVE -> REVISE -> FIND NEW GAPS

## Current operating rule

A gap is closed only by evidence appropriate to the claim.

## Community input

Use the IMA learning contribution issue template to report an unknown, correction, technology, research result, test, teaching need, or cultural/language contribution.
