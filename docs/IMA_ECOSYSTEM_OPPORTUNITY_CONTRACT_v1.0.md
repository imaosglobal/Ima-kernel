# IMA Ecosystem Opportunity Contract v1.0

Status: canonical implementation contract
Date: 2026-11-16

## Purpose

IMA evaluates not only a product or launch itself, but the complete ecosystem around it. This applies to games, software, AI, devices, media, services, infrastructure, research, standards and future categories.

## Opportunity surface

For every material opportunity, inspect when relevant:

1. Core product/service/technology.
2. Launch, release and lifecycle events.
3. Official ecosystem, platform and distribution channels.
4. Companion products, accessories, merchandise and licensing.
5. Advertising, sponsorship and commercial formats.
6. Content ecosystem: guides, analysis, creators, communities, media and education.
7. APIs, SDKs, MCP/agent interfaces, integrations and developer programs.
8. Competitors, substitutes, adjacent solutions and partnerships.
9. User needs, accessibility and underserved audiences.
10. Business models, value capture and zero-cost/reversible tests.
11. Legal/IP/licensing/terms/privacy/safety/authorization constraints.
12. IMA capability fit and reusable canonical components.
13. Evidence quality, uncertainty and measurable outcomes.

## Canonical execution

DISCOVER → MAP ECOSYSTEM → VERIFY EVIDENCE → CHECK AUTHORITY/IP/TERMS/PRIVACY/SAFETY → REUSE IMA → BUILD ONLY MISSING REUSABLE CAPABILITY → INTEGRATE → TEST END-TO-END → DEPLOY → RUNTIME VERIFY → MEASURE VALUE → DOCUMENT PROVENANCE → REGRESSION TEST.

## Truth states

planned ≠ implemented ≠ deployed ≠ runtime-verified ≠ usable-now ≠ successful.

No opportunity is declared successful without evidence appropriate to the claimed outcome.

## Action boundary

IMA may execute authorized, reversible, zero-cost technical work. It must not purchase, spend, send unsolicited outreach, make irreversible commitments, or represent unverified partnerships/approval/licensing as real without explicit authorization and evidence.

## Anti-duplication

This contract is part of the single canonical IMA super-task. It does not create a separate scanner, app, site, task or opportunity system.
