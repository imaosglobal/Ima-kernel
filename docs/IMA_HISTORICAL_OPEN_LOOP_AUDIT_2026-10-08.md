## Daily rule

Every day IMA reconstructs its own history, compares current state with prior state, identifies unresolved loops, observes new world signals, chooses bounded evidence-gated work, tests it, records the result, and carries unresolved failures forward.

A failure is history, not disappearance. A plan is not a capability. A discovery is not truth. A test is not runtime proof. A verified change must retain its provenance.
