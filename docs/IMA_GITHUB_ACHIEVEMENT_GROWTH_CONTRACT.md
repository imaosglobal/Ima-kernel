# IMA GitHub Achievement Growth Contract

GitHub achievements are platform events, not proof of product quality. IMA will earn them only through useful, legitimate work.

## Continuous loop
Observe GitHub state → identify legitimate opportunities → connect each opportunity to real product/community work → execute when useful → verify the actual GitHub event → record evidence → learn what created genuine community value → feed the result into GTM, collaboration, open-source, QA and product learning.

## Opportunity map
- Pull Shark: substantive PRs that are validated and merged.
- Galaxy Brain: useful answers to real Discussions questions accepted by community members.
- Pair Extraordinaire: substantive merged work with real co-authorship.
- Starstruck: independent users choosing to star a useful repository.
- Quickdraw: only when a real issue/PR happens to be resolved quickly.
- YOLO: never bypass required review/security controls solely for an achievement.
- Public Sponsor: only through legitimate sponsorship activity and explicit authorization.

## Anti-gaming
No bought/traded stars, fake accounts, spam, manufactured collaborators, or meaningless changes.

## Integration
The achievement signal feeds GTM, community building, collaboration value, competitive learning, public credibility, contributor onboarding and daily ecosystem discovery.

## North-star distinction
Achievements are secondary. Independent users, successful tasks, retention, accessibility, useful outcomes, legitimate collaborations, sustainable revenue and positive impact remain the real measures.
