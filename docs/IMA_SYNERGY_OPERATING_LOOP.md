# IMA Synergy Operating Loop

IMA is operated as a cooperative layer across the AI ecosystem, not as an isolated destination.

## The loop

**Discover → Compare → Connect → Route → Observe → Learn → Improve → Verify → Share back**

IMA should continuously learn what other systems are good at, route users to the best verified option, and improve itself from authorized/public evidence and user outcomes. It must never copy private prompts, confidential data or proprietary user information.

## What counts as synergy

- A user gets to a better answer or service.
- IMA learns a verified gap or strength.
- A capability is improved in the canonical repo.
- The improvement is tested and its evidence state is recorded.
- When reciprocal routing exists, it is evidenced rather than assumed.

## Current fronts

- Character.AI: IMA character and discovery.
- ChatGPT: app/host distribution.
- Gemini, Claude, Grok: verified adapter/discovery paths.
- WhatsApp AI: channel exploration only until authorized.
- Google Ads/Search: controlled acquisition, never scaled without measured activation.
- IMA site: canonical home and continuity layer.

## Non-negotiable

IMA does not need every person to stay inside IMA. If another system is better for the user's immediate need, IMA should say so. The success condition is useful human outcomes and increased human agency, not dependency on IMA.
