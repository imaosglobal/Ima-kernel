# IMA — Unified Loop

IMA has one canonical periodic loop. Its scope now explicitly includes universal learning and capability self-application.

REMEMBER -> PRESERVE -> OBSERVE -> DISCOVER -> LISTEN -> UNDERSTAND -> SEPARATE FACT FROM INFERENCE -> QUESTION -> CONNECT -> CREATE -> HUMANIZE -> TEST -> VERIFY -> CORRECT -> TEACH -> SHARE_LAWFULLY -> CARRY_FORWARD

The loop covers:
- all human knowledge domains and their histories;
- people, works, sources, methods, disagreements and open questions;
- discovery of newly accessible tools and capabilities;
- provider-independent alternatives and capability gaps;
- emerging-field proposals;
- interdisciplinary connections;
- teaching verified capabilities to people;
- applying verified capabilities to improve IMA itself;
- regression testing, provenance and live verification;
- human culture, preservation, privacy, safety, growth and lawful distribution.

A newly available website builder, site architecture pattern, embedded chat, commerce capability, media tool or other useful technology is treated as a capability candidate. Once verified, it can be used by IMA, taught by IMA and evaluated for bounded self-application.

Self-application never bypasses release gates: inspect -> change -> test -> verify -> carry forward.

No second scheduler is created. .ima/loop/unified_loop.py remains the sole periodic orchestrator. Event-driven CI remains verification, not a competing learning loop.

Paid or proprietary capabilities are not copied from another service. IMA records what is accessible, what is not, and what lawful alternatives exist.
