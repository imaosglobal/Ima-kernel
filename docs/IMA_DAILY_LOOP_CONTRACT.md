# IMA Unified Daily Loop Contract

Status: canonical integration contract. It does not create a second automation.
Date: 2026-10-22

## Sole orchestrator
The existing unified daily IMA Global Health Loop remains the sole cross-domain daily orchestrator.

## Required workstreams
Its existing workstreams remain active. The Creator-to-Commerce/business workstream must use, in the same daily run:
- IMA System Truth & Capability Map
- Human Agency Gate
- Revenue Evidence Loop
- Financial Evidence Ledger
- IMA Global Nonprofit Charter
- IMA Creator Succession & Estate policy
- existing privacy, consent, zero-duplication and evidence gates

## Required daily behavior
1. Discover current state.
2. Check evidence and stale/expired claims.
3. Identify gaps.
4. Prepare only authorized changes/actions.
5. Execute only where authorization and verified permissions exist.
6. Verify the result.
7. Append significant transitions to the development journal.
8. Never create another daily automation for these domains.

## Failure behavior
A blocked or unverifiable step is recorded as FAILED or GAPS_RECORDED. The loop must not convert failure, absence of evidence, eligibility or projection into success or income.

## Financial boundary
No money movement occurs merely because the daily loop detected an opportunity or wrote a ledger entry.
