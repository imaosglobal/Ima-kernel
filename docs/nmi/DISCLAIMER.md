# Important status and safety disclaimer

NMI-1.0 is a standards proposal, not medical advice and not an approved medical standard.

It must not be used to change, stop, replace, or self-administer medication.

No prototype or experimental delivery mechanism should be tested on people outside an appropriately approved medical/research program.

The purpose of this project is standards research: to establish a rigorous framework for evaluating whether less-invasive medication-delivery approaches can safely meet the same clinical requirements as existing approaches.
