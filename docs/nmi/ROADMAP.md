# NMI Roadmap

## Phase 0 — Public draft
Status: prepared
- RFC
- gap analysis
- stakeholder map
- submission checklist
- outreach templates

## Phase 1 — Expert validation
- biomedical engineering review
- clinical review
- pharmacology/drug-delivery review
- regulatory review
- standards expert review
- patent/prior-art review

## Phase 2 — Public consultation
- publish issues
- collect comments
- publish responses
- revise NMI

## Phase 3 — National standards route
- contact SII
- determine technical committee
- submit official proposal if appropriate

## Phase 4 — International standards route
- coordinate through the relevant national standards body
- discuss with ISO/TC 84 or another appropriate home
- prepare NP if requested
- identify project leadership and participating experts

## Phase 5 — Evidence and implementation
- define test methods
- define conformity-assessment approach
- define implementation profiles
- create examples without making clinical claims

## Phase 6 — Future revisions
Trigger review when:
- a relevant international standard changes
- major new drug-delivery technology appears
- significant clinical evidence changes the risk/benefit landscape
- regulators issue new guidance
- public review identifies a material defect
