# Outreach templates

## SII — request for standards-route guidance

Subject: Proposal for a public technical standard on minimum necessary invasiveness in medication delivery

Dear Standards Institution of Israel,

I am developing an open technical proposal titled “NMI — Minimum Necessary Invasiveness for Medication Delivery.”

The proposal does not attempt to replace existing device-specific standards. It proposes a technology-neutral framework for evaluating medication-delivery routes according to the minimum level of invasiveness necessary to achieve the required clinical outcome, while preserving requirements for safety, efficacy, dose accuracy and delivery reliability.

I would like to understand:
1. which existing Israeli standards committee is the appropriate technical home;
2. whether the proposal should be submitted as a request for a new Israeli standard, revision, or another form of standards work;
3. which documents and evidence are required for an initial submission.

I have prepared a public draft, standards-gap analysis and stakeholder map for expert review.

Sincerely,
Ori Cohen

## International standards inquiry

Subject: NMI proposal — minimum necessary invasiveness in medication delivery

Dear Secretariat/Committee,

I am seeking guidance on whether a technology-neutral framework for “Minimum Necessary Invasiveness” in medication delivery could be suitable for work within the existing standards structure.

The proposal is intended to complement, not duplicate, device-specific standards such as ISO 21649 for needle-free injection systems.

The proposed framework addresses route comparison, invasiveness classification, delivery-performance requirements, evidence, monitoring and fail-safe principles.

I would appreciate guidance on:
- scope fit;
- existing work that should be incorporated;
- the appropriate working group or committee;
- whether a preliminary work item or new work item proposal would be appropriate.

Sincerely,
Ori Cohen
