# Submission Checklist

## Before contacting a standards body
- [ ] Freeze NMI-1.0 Public Draft.
- [ ] Add author identity and date.
- [ ] Add evidence bibliography.
- [ ] Complete standards-gap analysis.
- [ ] Identify existing standards that must be referenced rather than duplicated.
- [ ] Obtain expert review from medicine, biomedical engineering, regulatory affairs and standards professionals.
- [ ] Declare conflicts of interest.
- [ ] Perform a patent/prior-art review.
- [ ] Define intended scope precisely.
- [ ] Prepare a one-page proposal.

## Israel
- [ ] Contact SII standardization division.
- [ ] Ask which existing committee should receive the proposal.
- [ ] Ask for the official current application form and process.
- [ ] Submit only through the official SII process.
- [ ] Preserve confirmation/reference number.

## International
- [ ] Approach the relevant ISO committee/secretariat through the appropriate national standards-body route.
- [ ] Discuss scope before submitting an NP.
- [ ] Prepare an ISO New Work Item Proposal package if invited.
- [ ] Identify a qualified project leader.
- [ ] Provide market-relevance justification and initial draft.

## Publication
- [ ] Publish versioned RFC repository.
- [ ] Publish a release archive.
- [ ] Deposit release in Zenodo.
- [ ] Obtain DOI.
- [ ] Maintain issue tracker and change log.
- [ ] Never label the draft as an official standard.
