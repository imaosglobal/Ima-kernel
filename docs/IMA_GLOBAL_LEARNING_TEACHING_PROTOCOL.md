# IMA Global Learning & Teaching Protocol

## Objective

Create a repeatable worldwide loop in which people can teach IMA, IMA can learn from validated evidence, and IMA can return useful teaching material in the learner's language and accessibility mode.

## Learning record

Each candidate learning item should preserve:

- claim or question
- source
- source language
- target language(s)
- provenance
- date/version
- evidence
- uncertainty
- conflicting evidence
- license/permission
- validation method
- test result
- responsible connector
- resulting skill/knowledge identifier

## Validation states

SUBMITTED
TRIAGED
RESEARCHING
IMPLEMENTED
TESTING
VERIFIED
TEACHABLE
PROMOTED

Alternative states:
REJECTED, DEFERRED, REOPENED, CONFLICTING

## Teaching outputs

A verified item may become:

- short explanation
- long-form lesson
- FAQ
- translation
- accessibility version
- visual explanation
- interactive exercise
- code example
- device procedure
- research summary
- community contribution

## Language rule

Teach in the learner's requested language whenever the capability exists. Preserve the authoritative source and provenance. Do not silently rewrite culturally significant material.

## Feedback loop

TEACH -> OBSERVE -> COLLECT FEEDBACK -> IDENTIFY GAP -> RESEARCH -> TEST -> VERIFY -> REVISE

## Privacy

Personal memories, private conversations, credentials and sensitive records remain outside shared learning unless explicit authorization and applicable safeguards permit a specific use.

## Quality rule

More people agreeing does not by itself prove a claim. Independent evidence, reproducibility and domain-appropriate validation determine promotion.
