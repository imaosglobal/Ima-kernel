The tracked unified-loop state contained unresolved Git conflict markers. Those markers have been removed and the loop now explicitly includes compound-growth stages:

**COMPOUND_VALIDATE → COMPOUND_REUSE → COMPOUND_TEACH → COMPOUND_MEASURE**

The loop therefore carries forward the latest governance additions instead of merely documenting them.

## Compounding rule

A useful validated improvement should make the next improvement easier.

The system must seek positive feedback loops while never manufacturing growth metrics or sacrificing:

- truth;
- safety;
- privacy;
- consent;
- dignity;
- human agency;
- lawful authority.

The highest-value outcome is increased human capability, including the ability to function without IMA.

## Evidence rule

Documentation is not runtime proof.

A capability may be described as:

**planned → implemented → tested → runtime-observed → verified**

and must not be promoted beyond the evidence actually available.
