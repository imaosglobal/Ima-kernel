# IMA — Global Growth, Real Users & User Truth

## Principle

IMA must grow by being genuinely useful, discoverable, accessible and trustworthy—not by fabricating users, ratings, reviews, followers or engagement.

The canonical growth funnel is:

DISCOVER → VISIT → START → RETURN → VALUE → FEEDBACK → IMPROVE → SHARE → RETURN

A metric is considered real only when it comes from an actual instrumented event or an independently verifiable platform source.

## Real-user truth

IMA distinguishes:
- anonymous visits;
- installations;
- authenticated users;
- first meaningful conversation;
- returning users;
- retained users;
- active communities;
- feedback submissions;
- voluntary shares;
- verified app-store installs/ratings/reviews;
- partnerships and institutional usage.

Missing data is UNKNOWN, never zero.

## Growth surfaces

1. Fast public web entry and SEO.
2. PWA install and mobile-first UX.
3. Android distribution and Play Store readiness.
4. Multilingual landing pages and localized onboarding.
5. Search/AEO/GEO content answering real human questions.
6. Community and education partnerships.
7. Creator/artist/science/culture use cases.
8. Accessibility-first onboarding.
9. Referral/share flows based on voluntary sharing.
10. Product-led retention: memory controls, creation, learning, culture and useful tools.
11. Feedback-driven iteration.
12. App-store reputation based only on real users and real ratings.
13. Public changelog and transparent capability truth.
14. Research/evaluation partnerships.
15. lawful press/community outreach using authorized accounts.

## Anti-fraud gates

Never:
- buy or fabricate users;
- fabricate ratings/reviews;
- create fake accounts;
- incentivize deceptive reviews;
- spam DMs/comments;
- impersonate people or organizations;
- scrape private user data for targeting;
- claim a platform listing exists before it is verified.

## Growth metrics

At minimum track:
- visits;
- unique visitors where the analytics provider supports privacy-preserving aggregation;
- starts;
- authenticated sign-ins;
- first meaningful interaction;
- returning users;
- retention D1/D7/D30 where sample size permits;
- feedback;
- satisfaction signal;
- error rate;
- latency;
- shares;
- referral attribution;
- install events;
- app-store ratings/reviews only from platform APIs or verified manual evidence.

## Cadence

- Continuous: errors, latency, safety, auth and feedback ingestion.
- Hourly: canonical health and growth instrumentation checks.
- Daily: funnel, feedback themes, accessibility, localization and SEO gaps.
- Weekly: retention/cohort review and content/channel experiments.
- Monthly: market/channel review and app-store/partnership readiness.
- Quarterly: internationalization, safety, pricing/economics and product strategy.
- Yearly: architecture, governance, preservation and long-term continuity.
- Decadal/long-term: portability, preservation, cultural continuity and succession.

Every cadence reconciles through the single IMA unified loop.

## Success condition

The goal is not a large number alone. The goal is a growing population of real people who voluntarily return because IMA improves something in their lives, while preserving their agency, privacy and cultures.
