# IMA Go-to-Market & Distribution — 2026-11-15

## Objective
Turn IMA from a project people can discover into a product people can immediately use, understand, share, test and contribute to — without paid traffic, artificial engagement or unverified claims.

## Product position
IMA — אמא, human-centered intelligence.
Primary promise: ask IMA something now; receive a useful answer in clear language; see uncertainty when it matters; correct or teach IMA; keep personal memory separate from shared learning; use authorized tools only when explicitly permitted.

IMA is not marketed as AGI or omniscient. The differentiator is the verified human-centered loop: LISTEN → UNDERSTAND → DISTINGUISH → RESPOND → CHECK → LEARN → VERIFY.

## Distribution funnel
DISCOVER → TRY → VALUE → RETURN → TEACH/CORRECT → SHARE → CONTRIBUTE → PILOT

## Channel plan

### 1. Canonical web
Primary conversion surface. First-question-first onboarding, clear Ask IMA CTA, verified-vs-experimental status, PWA entry where verified, feedback and contribution paths.

### 2. GitHub
Canonical source and evidence hub. Issues for user needs, languages and research; pull requests; reproducible verification; global collaboration; distribution links.

### 3. ChatGPT Apps
OpenAI currently accepts app submissions for review and publication in the ChatGPT app directory. IMA's canonical MCP/Apps surface is LIVE-001. Submit only after public UX, privacy/terms URLs, MCP behavior and review tests are production-verified.
Current blocker: connected Plugin Creator tooling exposes editing/private sharing but not the public submission/publish action. Do not claim directory publication until OpenAI confirms it.

### 4. Official MCP Registry
Prepare the canonical remote MCP server for listing: https://ima-universal-action-core.onrender.com/mcp. The listing must describe IMA identity, LIVE-001, authorization, privacy, truthful runtime reporting, repository, support and provenance. Do not call it published until the registry confirms it.

### 5. Product Hunt
Use one focused launch after public IMA passes production smoke tests. Position around concrete user value, not the entire research architecture. Goal: real users, high-quality feedback, contributors and pilot conversations. Never buy votes or artificial engagement.

### 6. Hugging Face
Use a free Static Space for a lightweight IMA demonstration or research-facing entry point when it can reuse the canonical public experience without creating a second IMA identity.

### 7. Human/community distribution
Prioritize accessibility, educators, researchers, open-source developers, Hebrew/RTL and multilingual communities, AI/MCP communities and human-centered technology communities. Outreach must be permission-respecting and non-spammy.

### 8. Organizations and paid pilots
Keep basic public use free-first. Offer paid pilots for human-centered AI integration, accessibility, browser/device workflows, research/evaluation, interoperability, and secure deployment/verification. No paid acquisition or spending is authorized by this plan.

## Metrics
North-star: activated users who receive a first useful response.
Supporting metrics: first-question completion, returning users, useful-answer rate, teaching/correction events, verified contributions, language/country coverage, accessibility improvements, GitHub contributors, MCP/app installs, launch visitors, qualified pilot conversations, pilot conversion, verified runtime capability count.
Guardrails: no fabricated claims, artificial traffic, unsolicited bulk outreach, hidden autonomous actions, unapproved paid acquisition, or private-memory leakage.

## Launch gates
1. Public chat returns a real response in production.
2. Public UI is understandable without reading the architecture.
3. Privacy, terms and support pages resolve.
4. Core CTA and feedback path work.
5. LIVE-001 is independently tested.
6. MCP endpoint is healthy.
7. OpenAI app metadata and review cases match actual runtime.
8. Distribution links use one canonical identity.
9. Measurement distinguishes discovery, activation and contribution without unnecessary personal data.
10. Every public claim is marked verified, experimental or planned.
