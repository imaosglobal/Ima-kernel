# IMA — App Store / Google Play Verified Growth Launch

## Truth gate

No store install, rating, review or user count is reported as real until the public listing is independently verified.

## Android launch gates

- [ ] Release APK/AAB builds reproducibly.
- [ ] Application ID: `com.ima.core`.
- [ ] Current target SDK and dependencies pass release checks.
- [ ] Google Credential Manager sign-in is tested on a real device.
- [ ] Privacy policy is publicly reachable.
- [ ] Support URL is publicly reachable.
- [ ] Data safety declaration matches actual collection.
- [ ] Account deletion/export behavior is documented and tested.
- [ ] Child/age-assurance behavior is accurately disclosed.
- [ ] Store screenshots show the actual current product.
- [ ] Store description matches implemented capabilities.
- [ ] Store listing is published and verified.
- [ ] Install is verified from the public listing.
- [ ] At least one real user completes onboarding.
- [ ] Feedback event reaches the configured analytics/feedback system.
- [ ] Rating/review is requested only after meaningful use.

## ASO

Use real user problems as search intent:
- AI assistant for learning
- personal AI companion
- multilingual AI
- human-centered AI
- AI memory with user control
- creative AI
- AI for education
- culture and history learning
- accessibility and multilingual conversation

Do not use claims such as “millions of users”, “best AI”, or “human-level” without independently verifiable evidence.

## Reputation loop

REAL USE → VALUE → OPTIONAL RATING REQUEST → REAL REVIEW → ANALYZE → FIX → RELEASE → REPEAT

Negative reviews are product evidence, not something to suppress.

## International rollout

Prepare localized store metadata for Hebrew, English, Arabic, Spanish, French, Portuguese, German, Hindi, Japanese, Korean and Chinese. Publish only translations that have been reviewed for meaning, safety and cultural context.
