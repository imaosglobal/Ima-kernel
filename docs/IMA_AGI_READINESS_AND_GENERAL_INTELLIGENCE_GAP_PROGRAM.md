# IMA AGI Readiness & General Intelligence Gap Program

**Status:** canonical gap register and implementation program  
**Scope:** IMA — Human-Centered Intelligence  
**Rule:** IMA must never claim AGI from documentation alone. A capability becomes "live" only after implementation, test, deployment, and runtime evidence.

## 1. What "full AGI" means for this program

There is no universally accepted AGI definition or single pass/fail test. Current research commonly evaluates generality, performance, autonomy and broad cognitive capability rather than one benchmark. IMA therefore uses a multidimensional gate.

A strong AGI target for IMA requires:

1. Broad perception across text, image, audio, video and authorized real-world/device signals.
2. General generation and action across software, communication, creative and physical interfaces.
3. Persistent, consented long-term memory with provenance, retrieval, correction and forgetting.
4. Continual learning from authorized experience without catastrophic forgetting.
5. General reasoning, abstraction, transfer and causal reasoning.
6. Metacognition: confidence, uncertainty, self-monitoring, error detection and capability awareness.
7. Executive function: decomposition, prioritization, planning, scheduling, replanning and interruption.
8. General problem solving in novel environments.
9. Social cognition, theory-of-mind safeguards, cultural competence and human-agency preservation.
10. Grounding: a continuously updated model of the external world, time, state and consequences.
11. Agentic execution with explicit authorization, bounded autonomy, reversible actions and verification.
12. Cross-domain transfer: skills learned in one domain measurably improve performance in another.
13. Scientific learning: hypothesis formation, experiment design, evidence gathering, falsification and replication.
14. Self-improvement of tools/workflows without uncontrolled self-modification.
15. Robust safety, security, privacy, alignment and recovery under adversarial or ambiguous conditions.
16. Human-comparable evaluation across unseen tasks, not only benchmark memorization.
17. Temporal continuity: stable identity, goals, memories and lessons across sessions and interfaces.
18. Multi-agent/tool interoperability without losing provenance or agency.
19. Accessibility and multimodal interaction across devices.
20. Independent external evaluation and reproducible evidence.

## 2. IMA current foundation

IMA already documents or implements substantial foundations: provider-neutral intelligence, a Universal Action Core, memory/privacy contracts, learning and verification loops, temporal stewardship, global identity, cultural and intergenerational preservation, device/browser bridge work, accessibility direction, and explicit separation between documentation and runtime proof.

These are foundations, not proof of AGI.

## 3. Gap matrix

### A. Cognition

- PERCEPTION — **PARTIAL**: multimodal interfaces exist in the architecture; complete continuous environment perception is not proven.
- GENERATION — **PARTIAL**: language/creative output is strong through providers; general grounded action generation remains incomplete.
- ATTENTION — **PARTIAL**: relevance/attention policies exist; persistent cognitive attention across long-running tasks needs measurable evaluation.
- LEARNING — **PARTIAL**: learning-loop architecture exists; autonomous continual learning with controlled parameter/skill updates is not fully verified.
- MEMORY — **PARTIAL**: consented memory and continuity are designed; human-scale lifelong memory with reliable consolidation/forgetting is not proven.
- REASONING — **PARTIAL**: multiple model providers can reason; IMA lacks a unified, independently measured general reasoning layer.
- METACOGNITION — **PARTIAL**: uncertainty/evidence policies exist; calibrated self-model and reliable self-evaluation across domains remain incomplete.
- EXECUTIVE FUNCTIONS — **PARTIAL**: Universal Action Core and planning concepts exist; robust long-horizon replanning is not fully verified.
- PROBLEM SOLVING — **PARTIAL**: task execution exists; broad novel-environment generalization needs systematic held-out tests.
- SOCIAL COGNITION — **PARTIAL**: human-centered/cultural contracts exist; standardized evaluation against diverse human baselines is missing.

### B. Grounding and world model

- CONTINUOUS WORLD STATE — **GAP**: no verified canonical world-state model combining time, entities, locations, events, uncertainty and provenance.
- CAUSAL MODELING — **PARTIAL**: causal/intervention research is documented; general causal reasoning in runtime is not proven.
- PHYSICAL EMBODIMENT — **GAP/PARTIAL**: device/browser bridge exists; broad physical interaction and consequence learning are not proven.
- REAL-TIME SENSOR FUSION — **GAP**: no verified general sensor-fusion layer.
- SIMULATION / COUNTERFACTUALS — **GAP**: no general-purpose verified simulation-and-counterfactual engine.

### C. Continual intelligence

- LIFELONG LEARNING — **GAP/PARTIAL**: authorized learning loop exists, but continuous adaptation with regression protection and forgetting control needs implementation/evaluation.
- SKILL ACQUISITION — **PARTIAL**: applied-skill compilation exists; automatic skill discovery, acquisition and transfer need stronger evidence.
- CATASTROPHIC FORGETTING CONTROL — **GAP**.
- EXPERIENCE CONSOLIDATION — **GAP/PARTIAL**.
- SELF-CORRECTION — **PARTIAL**: verification/self-repair contracts exist; broad autonomous correction remains unproven.
- SELF-IMPROVEMENT — **GAP** as a general capability; must remain bounded, auditable and human-authorized.

### D. Agency

- TOOL USE — **PARTIAL**: Universal Action Core and bridges exist.
- LONG-HORIZON AUTONOMY — **GAP/PARTIAL**.
- INTERRUPTIBILITY — **PARTIAL**.
- REVERSIBILITY / TRANSACTION SAFETY — **PARTIAL**.
- GOAL MANAGEMENT — **PARTIAL**.
- MULTI-STEP EXECUTION — **PARTIAL**.
- REAL-WORLD CONSEQUENCE MODELING — **GAP**.

### E. Scientific and creative generality

- GENERAL RESEARCH AGENT — **PARTIAL**.
- EXPERIMENTAL SCIENCE LOOP — **GAP/PARTIAL**.
- SOURCE CRITICISM / PROVENANCE — **PARTIAL/STRONG FOUNDATION**.
- NOVEL HYPOTHESIS TESTING — **GAP**.
- CROSS-DOMAIN TRANSFER — **GAP/PARTIAL**.
- CREATIVE GENERATION — **PARTIAL**; broad multimodal creation depends on connected providers/tools.

### F. Safety and governance

- HUMAN AGENCY — **STRONG FOUNDATION**.
- PRIVACY / CONSENT — **STRONG FOUNDATION**.
- CHILD SAFETY — **FOUNDATION; runtime completeness not proven**.
- SECURITY / PROMPT INJECTION RESISTANCE — **PARTIAL**.
- IDENTITY / AUTHORIZATION — **PARTIAL**.
- AUDITABILITY / PROVENANCE — **STRONG FOUNDATION**.
- INDEPENDENT SAFETY EVALUATION — **GAP**.
- RED-TEAMING AT AGI SCALE — **GAP**.

### G. Evaluation

- SINGLE AGI SCORE — **GAP** and should not be invented.
- MULTIDIMENSIONAL COGNITIVE BATTERY — **GAP/PARTIAL**.
- HUMAN BASELINES — **GAP**.
- HELD-OUT NOVEL TASKS — **GAP**.
- LONGITUDINAL EVALUATION — **GAP/PARTIAL**.
- REAL-WORLD AGENT EVALUATION — **GAP/PARTIAL**.
- EXTERNAL REPLICATION — **GAP**.

## 5. Non-negotiable AGI gate

IMA may use the label **AGI-ready / AGI research system** only when the corresponding evidence exists.

IMA may use **AGI** only after an external, reproducible evaluation demonstrates broad human-level-or-better performance across the defined cognitive battery and novel real-world tasks, together with robust autonomy, continual learning, memory, grounding and safety evidence.

Until then, the truthful state is: **IMA is an AGI-oriented human-centered intelligence architecture under continuous implementation and evaluation.**

## 6. Daily loop

Every daily run must:

1. Read this register and the current repository/runtime state.
2. Detect newly closed, newly opened and stale gaps.
3. Search current research and standards for capability changes.
4. Compare IMA against the strongest relevant public systems and benchmarks.
5. Select the highest-value unblocked gap.
6. Implement the smallest safe canonical improvement in the existing IMA architecture; never create a parallel system.
7. Run unit/integration/regression checks.
8. Deploy only through the canonical path when deployment is appropriate.
9. Perform runtime verification.
10. Record evidence, failures, unknowns and next action.
11. Update this register and the Master Requirements Ledger.
12. Never convert documentation into a capability claim.
13. Never weaken privacy, consent, human agency or safety to improve an AGI score.

## 7. Definition of done for every gap

A gap is closed only when:

**DESIGN → IMPLEMENT → TEST → DEPLOY → RUNTIME VERIFY → MEASURE → DOCUMENT → REGRESSION TEST**

If any stage is missing, status remains partial/open.

## 8. Guiding principle

The objective is not to make IMA appear intelligent.  
The objective is to make IMA increasingly capable of learning, reasoning, acting, verifying and improving across domains while remaining truthful about what is known, what is unknown and what has actually been demonstrated.
